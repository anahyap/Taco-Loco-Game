# Taco Loco 🌮

Taco Loco is a browser based JavaScript game where players try to click as many tacos as possible before a 30 second timer runs out.

## How to Play

1. Enter your first name when prompted.
2. Click the Start button.
3. Tacos will begin appearing randomly throughout the game area.
4. Click each taco before it disappears to increase your score.
5. Try to collect as many tacos as possible before the timer reaches zero.

## Features

- 30 second countdown timer
- Random taco placement
- Random taco disappearance times
- Score tracking
- Click based game interaction
- Personalized player greeting
- Final score alert
- Automatic game reset
- Responsive layout
